Lecture demos — ethers console harness

Open the browser console (F12) and paste one demo at a time. The globals p (Sepolia), pMain (mainnet), link, and weth are already set up for you. Everything is a free, read-only call.

Demo 1 (Lecture 2.10) — the Provider, reading the chain live

await p.getBlockNumber();                       // latest block height
await p.getFeeData();                           // current gas price / fees
const bal = await p.getBalance(SAMPLE_ADDRESS); // balance, in wei
ethers.formatEther(bal);                        // the same value, in ether
await pMain.resolveName('ens.eth');             // ENS -> address (mainnet)

Demo 2 (Lecture 2.11) — the Contract, reading a deployed token

await link.name();                    // "ChainLink Token"
await link.symbol();                  // "LINK"
const b = await link.balanceOf(SAMPLE_ADDRESS);
ethers.formatUnits(b, 18);            // decoded with a 3-line hand-written ABI

Demo 3 (Lecture 2.12) — events, history then live

// historic: past Transfers over the last 20 blocks
const logs = await weth.queryFilter('Transfer', -20, 'latest');
logs.length; logs[0].args;            // { from, to, value }

// live: one line per new Transfer as it is mined (wait a few seconds)
const h = (from, to, value) => console.log(from, '→', to, value.toString());
weth.on('Transfer', h);
// ...watch the console fill, then stop the subscription:
weth.off('Transfer', h);
